# coder-pictures

Before and after pictures for the Studio coder's pull request reviews (buka-watch and buka-site).

- The governor writes them here, one folder per review: `<repo>/<pr>/<head commit>/`.
- They show public pages only, loaded with fake data. Never real customer data (POPIA).
- The repo is public so the pictures show in the GitHub app on a phone. Private repos cannot do that.
- Nothing here is a golden copy. Every review compares the PR with main in the same run.
